# Kanri

Kanri est un carnet de ventes : tu crées tes boutiques, tu notes ce que tu gagnes et ce que tu dépenses, et le site prévoit tes commandes des 7 prochains jours.

Tout tient dans `index.html` (HTML, CSS et JavaScript, sans installation).

## Où sont enregistrées les données

Sur ce site (GitHub Pages), les boutiques et les montants sont enregistrés dans le navigateur de la personne qui l'utilise. Ils ne sont envoyés nulle part.

L'assistant IA et l'enregistrement dans le compte ne fonctionnent que dans la version ouverte depuis Claude.

## Mettre le site en ligne

Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
